Capacitive Sensor

For the capacitive sensor, I put parallel plates together. I was thinking this could be useful to gauge a distance threshold in a final project—for example, if the drawing device could be used to trace outlines of foreign objects. I used alligator clips and stripped some wire to connect the copper to the esp32.
The device worked—as shown here, it was pretty responsive and consistent when you pressed the copper together vs. when you don’t. I forgot to take a video, but I have a screenshot of the readings and my code below.
                                

int tx_pin = 19;
int rx_pin = 21;

int read_high;
int read_low;
int read_result;

int N_samples = 100;
int sum;

void setup() {
  pinMode(tx_pin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  sum = 0;

  for (int i=0; i < 1*N; i++) {
    digitalWrite(tx_pin, HIGH);
    read_high = analogRead(rx_pin);
    digitalWrite(tx_pin, LOW);
    read_low = analogRead(rx_pin);
    read_result = read_high - read_low;
    sum += read_result;
  }

  Serial.println(sum);
}

Human sensor

For the other sensor, I decided to make a human detector. Touch the thermistor, and the light should go off if you’re alive. That was the goal.
Thus, I adapted the code from the course site. Given the linear equation from the manufacturer to get temperature, I decided the easiest way to calibrate it would be to adjust based on the calculated error. Thus, given the data points that 23 and 37 celsius read as 40 and 55 respectively, I used the equation T = .7 * T - 5, and that was pretty functional within the ranges of room temperature to body temperature!
Minor snafu: I have extremely cold fingers, so I actually read as non-human. However, conscripting Bobby’s fingers did get the little light to turn on. As did rubbing the thermistor to get enough friction. Yay.
                                
int ThermistorPin = 33;
int Vo;
float R1 = 10000;
float R2, T;
float A = 3.354e-03;
float B = 2.5698e-4;

// Define the LED pin 
int LED_PIN = 27;

void setup() {
  Serial.begin(9600);  
  // Set LED_PIN as an OUTPUT  
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  Vo = analogRead(ThermistorPin);
  R2 = R1 * 1/(4095.0 / (float)Vo - 1.0);  // Calculate thermistor resistance.
  T = 1.0 / (A + B * log(R1 / R2));         // Calculate temperature in Kelvin.
  T = T - 273.15;                           // Convert from Kelvin to Celsius.
  
  // Apply the calibration correction if needed
  // For example, if using: T = 0.7 * T - 5;
  // Uncomment the following line if you are using the calibration:
  T = 0.7 * T - 5;

  // Print temperature for debugging
  Serial.println(T);

  // Check if temperature exceeds 29°C
  if (T > 23) {
    digitalWrite(LED_PIN, HIGH); // Turn on the LED
  } else {
    digitalWrite(LED_PIN, LOW);  // Turn off the LED
  }

  delay(500); // Delay before next reading
}
