Week 4. Microcontroller Programming

Microcontroller Project

I mainly used this week to retool and improve last week’s work. I already used the ESP32 to spin clockwise and counterclockwise at different cadences and speeds. However, I found it most aesthetically pleasing to have it continue to swirl like the breeze. More on that in last week’s documentation.
Instead, then, I remade the rest of the sculpture. I remade the gears, first of all. Doing some research, I learned that you design planetary gears according to the equation R = 2 * P + S, here R = # of teeth in the ring gear, P = # of teeth in the planet gear, and S = # of teeth in the Sun gear. I figured I would try 80, 50, and 15 for R, S, and P respectively. Using a module of 1.5mm, this would get me to a nice and compact 133 mm outside diameter of the internal gear.
Moreover, I decided I would assemble a few plates of plywood to stabilize the stepper motor. I also measured and included scrap wood to use as supporting beams. You can see the sandwich-like layering I planned in the journal entries here. Moreover, you can see how I planned the plywood sandwich, including measurements.

const int stepPin = 18;
const int dirPin = 19;

void setup() {
  pinMode(dirPin, OUTPUT);
  pinMode(stepPin, OUTPUT);
  
}

void loop() {
  digitalWrite(dirPin,HIGH);
  for (int i =0; i < 10000; i++)
  {
    digitalWrite(stepPin, HIGH);
    delay(1);
    digitalWrite(stepPin, LOW);
    delay(1);
  }
  digitalWrite(dirPin,LOW);
  for (int i =0; i < 10; i++)
  {
    digitalWrite(stepPin, HIGH);
    delay(1);
    digitalWrite(stepPin, LOW);
    delay(1);
  }

}
