Weeks 13 & 14: The rest of it...

First, here are the finalized STL files: here and here
After my week 11 project iteration, the next major tasks were to improve the z-calibration of the end-effector, improve the data ingestion, and improve the user experience.
This work could have been more focused. I wanted to salvage the two-color drawing end effector and thereby facilitate multi-color drawing, but I kept running into issues with the pen dragging too much, coming off the paper, or pressing too hard. This was most frustrating when the end effector moved away from the base--the arm levers down, and as a result unreliable lines ensued. Now the square-design for pen plotters (and 3D printers, and laser-cutters) makes a lot moer sense to me. Dealing with that inconistent z-axis alignment when you need such precise alignment to the canvas is a huge pain.
Thus, I relegated the scope of the end effector to a single color. Even then, it was pretty cumbersome to calibrate. I had to adjust the sharpie up and down using a little screw-vice. To prevent it from dragging or getting caught, I used a couple of rubber bands to stabilize the pen #engineering.
I also spent a lot of time fiddling with the code. I had to tweak accelerations and top speeds to prevent image stretching (I accidentally used different gear ratios with the steppers, whoops). Bobby helped me work through a way to compress the array using the distance formula--combined with quadrupling the speed, it doodled at speeds I was happy with!
While the glue for the bottom of the box was drying, I started connecting all of the wires to the breadboard/Arduino with the tile slots inserted in the lid of the main box. One problem that I ran into, though, was that the metal pieces that I had hot glued were not completely flat because the soldering was not flat which made the connections between the number tiles and the pin wire metal a bit flakey. I also 3D printed out a plus sign and a minus sign tile to use for the second slot in the main box and had to put these two tiles together (screws, voltage divider, etc). I added an operator class to my code to accommodate these new tiles so that the plus sign (and tiles with digits 0-4) would be read as a "+" and the minus sign (and tiles with digits 5-9) would be read as a "-". I also added to the code so that you could see what numbers and which operator were being read on the serial monitor.
The wires were much more stiff than I thought they would be, so even without the bottom of the box, the lid could sit/float over the arduino and breadboard. Once I wired everything up, I tested out a few tiles and the serial monitor was printing the correct numbers (as long as you held down the tile in the third slot...)
Once the bottom of the main box was dry, I tried putting everything together. This was a bit tricky because the wires were so stiff and were a bit longer than necessary to reach the breadboard and arduino inside of the box, but after trimming some of the wires and bending some of the wires, I got everything to stay put. I also realized that I had not thought of a way to allow the cord connecting the arduino to my computer to go through the box, so I ended up lasercutting a hole in the remaining main box wall that I had not glued to everything else so that one end of the arduino could stick out and be plugged into my laptop. This hole was also useful because I decided that my output for my box would be my happy/sad toast from week 4, and the servo wires could also fit through the lasercut hole. I then had to do some combining of code for reading the number tiles with my servo code from week 4 so that the servo would rotate based on whether the equation created by the tiles was true or false. I had to experiment with the timing of checking the number values and other things because the code was sampling at too high a rate and the motor was just constantly moving around, but once I found a good amount of time between samples, the box seemed to be working pretty well! I also 3D printed a new stick for the toast to connect to the servo, since the wooden stick from week 4 was a bit too thin.
Unfortunately, the third tile slot was still not very reliable. I tried using double sided tape (again per Bobby's suggestion) to secure the tile slots in the box lid in a more stable position, but I couldn't get the position for the third slot quite right. I spent quite a while trying different amounts of tilting in each direction, but that spot is still probably the weakest part of the project (works for a bit and then stops working and then starts working again etc... as you can see in the video, it requires pressure in a very specific place to get a more constant, correct reading).
After working for a while on the third tile slot, I decided to finally move on and close up each of the tiles using tiny M1.4 screws. This also took much longer than I anticipated because the screws are so tiny and are very difficult to get into the 3D prints, but I eventually got them all closed up!
Yay!! I am very happy with how it all turned out. Definitely learned a lot and had a TON of fun with everything :) I do wish I could've gotten the project to work a bit more consistently, but I think it actually works a lot better than I expected it to. I am also happy that I got to make something that is related to early education, since that is the field that I am interested in going into after college!

// === Cursive-style path for "Hello" ===
struct Point {
  long x;
  long y;
};

float distance(long x1, long x2, long y1, long y2){

  return sqrt(pow(( x1-x2),2) +pow((y1-y2), 2));
}

int shortenPath(const Point ogPath[], Point newPath[], int numPoints, int minDist)
{
  int currIndex = 1;
  newPath[0] = ogPath[0];
  for(int i = 1; i < numPoints; i++)
  {
    if (distance(newPath[currIndex - 1].x, ogPath[i].x,newPath[currIndex - 1].y, ogPath[i].y) >= minDist){
      newPath[currIndex] = ogPath[i];
      currIndex++;
    }
  }
  return currIndex;
} 


Point finalPath[1500];

const Point helloPath[] = { //ADD INPUT ARRAY HERE
      };

void drawWord() {
  // Move to first point with pen up
  long startX = MIDDLE_INIT + finalPath[0].x * DRAWING_SCALE;
  long startY = -MIDDLE_INIT + finalPath[0].y * DRAWING_SCALE;
  servo.write(PEN_UP_ANGLE);
  stepper1.moveTo(startX);
  stepper2.moveTo(startY);
  while (stepper1.distanceToGo() != 0 || stepper2.distanceToGo() != 0) {
    stepper1.run();
    stepper2.run();
  }
  delay(100);

  // Pen down
  servo.write(PEN_DOWN_ANGLE);
  delay(100);

  // Draw scaled path
  for (int i = 1; i < numPoints; i++) {
    long x = MIDDLE_INIT + finalPath[i].x * DRAWING_SCALE;
    long y = -MIDDLE_INIT + finalPath[i].y * DRAWING_SCALE;

    stepper1.moveTo(x);
    stepper2.moveTo(y);
    while (stepper1.distanceToGo() != 0 || stepper2.distanceToGo() != 0) {
      stepper1.run();
      stepper2.run();
    }
    delay(10);
  }

  servo.write(PEN_UP_ANGLE);
  delay(100);
}

void setup() {
  Serial.begin(115200);
  while(!Serial){
    delay(1);
  }
  numPoints = shortenPath(helloPath, finalPath, sizeof(helloPath)/ sizeof(Point), 4);
  Serial.println("Distance");
  Serial.println(distance(149, 148, 163, 163));
  Serial.println(numPoints);
  for(int i = 0; i < numPoints; i++){
    Serial.print("x: ");
    Serial.print(finalPath[i].x);
    Serial.print(" y: ");
    Serial.println(finalPath[i].y);
  }
  
  pinMode(PEN_SWITCH_PIN, INPUT_PULLUP);
  pinMode(X_AXIS_LIMIT_SWITCH_PIN, INPUT_PULLUP);
  pinMode(Y_AXIS_LIMIT_SWITCH_PIN, INPUT_PULLUP);

  ESP32PWM::allocateTimer(0);
  ESP32PWM::allocateTimer(1);
  ESP32PWM::allocateTimer(2);
  ESP32PWM::allocateTimer(3);
  servo.setPeriodHertz(50);
  servo.attach(SERVO_PIN, 500, 2400);
  servo.write(PEN_UP_ANGLE);  // Start with pen up

  stepper1.setMaxSpeed(16000);
  stepper1.setAcceleration(3000);
  stepper2.setMaxSpeed(10000);
  stepper2.setAcceleration(3000);
  stepper1.setCurrentPosition(0);
  stepper2.setCurrentPosition(0);
}

void loop() {
  // === Pen Control via Switch ===
  int pen = digitalRead(PEN_SWITCH_PIN);
  if (pen != lastPenSwitchState) {
    if (pen == LOW) {
      servo.write(PEN_DOWN_ANGLE);
      Serial.println("Pen DOWN");
      penIsDown = true;
    } else {
      servo.write(PEN_UP_ANGLE);
      Serial.println("Pen UP");
      penIsDown = false;
    }
    lastPenSwitchState = pen;
  }

  // === Homing Sequence ===
  if (!y_axis_isHome || !x_axis_isHome) {
    if (!y_axis_isHome) {
      if (digitalRead(Y_AXIS_LIMIT_SWITCH_PIN) == LOW) {
        Serial.println("Y Home!");
        stepper2.move(-10);
        stepper2.setCurrentPosition(0);
        y_axis_isHome = true;
      } else {
        Serial.println("Y not triggered.");
        stepper2.move(400);
        stepper2.runToPosition();
      }
    } else if (!x_axis_isHome) {
      if (digitalRead(X_AXIS_LIMIT_SWITCH_PIN) == LOW) {
        Serial.println("X Home!");
        stepper1.move(10);
        stepper1.setCurrentPosition(0);
        x_axis_isHome = true;
      } else {
        Serial.println("X not triggered.");
        stepper1.move(-400);
        stepper1.runToPosition();
      }
    }
  }

  // === Center Then Draw Word ===
  else if (!isSetUp) {
    stepper1.moveTo(MIDDLE_INIT);
    stepper2.moveTo(-MIDDLE_INIT);
    stepper1.runToPosition();
    stepper2.runToPosition();
    isSetUp = true;

    hasDrawn = true;
